# QR Code Export Architecture

This document outlines the export architecture for the Qraft QR code generator, detailing the processes for PNG export, SVG export, and Clipboard operations.

## Key Change: Two-Layer Export

The export pipeline now has two layers:
1. **Base QR**: Generated by `qr-code-styling` (dots, eyes, colors, gradients, logo, background)
2. **Composition**: Qraft wrapper adds frame + CTA text around the base QR

## Core Principle

The preview and export **must** use the SAME source QR configuration. There should be no possibility of the exported QR code differing from what is shown in the preview window.

## Resolution Options

- 512, 1024, 2048, 4096px for the QR code portion.
- Frame adds additional pixels around it.
- **Note:** The SVG export button does not need a resolution setting since it is a vector format.

## Implementation: `qr-code-styling` API

The `qr-code-styling` library provides built-in methods for exporting the generated QR codes:
- `qrCodeInstance.getRawData('png')` → returns a `Blob`
- `qrCodeInstance.getRawData('svg')` → returns a `Blob`
- `qrCodeInstance.download({ name, extension })` → triggers a browser download

## Logo Plate Pre-Composition

1. If logo has plate enabled:
   a. Create off-screen canvas
   b. Draw plate shape (circle/rounded-rect/square) with plate color
   c. Draw logo image centered on plate
   d. Export composite as data URL
   e. Pass composite data URL as image to qr-code-styling
   f. Set imageSize to include plate dimensions
2. If no plate:
   a. Pass logo src directly to qr-code-styling

## PNG Export

### Updated PNG Export Flow

1. User clicks 'Download PNG'
2. Show loading state
3. Await `document.fonts.ready` (critical for CTA text)
4. Create `qr-code-styling` instance at export resolution
   - If logo plate: pre-composite logo+plate, inject as image
5. Get base QR as canvas/blob
6. If frame enabled:
   a. Calculate total dimensions: QR size + frame padding * 2 + border
   b. Create composition canvas at total dimensions
   c. Draw frame background (rounded rect or frame shape)
   d. Draw base QR centered within frame (offset by padding)
   e. If CTA text: draw text at appropriate position
   f. Draw frame border
   g. Export composition canvas as PNG blob
7. If no frame:
   a. Export base QR blob directly
8. Trigger download
9. Clear loading state

### Canvas Frame Rendering

```typescript
function drawFrame(ctx: CanvasRenderingContext2D, frame: QRFrame, totalWidth: number, totalHeight: number): void {
  // Draw frame background
  roundRect(ctx, 0, 0, totalWidth, totalHeight, frame.borderRadius);
  ctx.fillStyle = frame.backgroundColor;
  ctx.fill();
  
  // Draw frame border
  if (frame.borderWidth > 0) {
    ctx.strokeStyle = frame.color;
    ctx.lineWidth = frame.borderWidth;
    ctx.stroke();
  }
}

function drawCTAText(ctx: CanvasRenderingContext2D, cta: QRCTAText, frame: QRFrame, totalWidth: number, qrSize: number): void {
  ctx.font = `${cta.fontWeight} ${cta.fontSize}px ${cta.fontFamily}`;
  ctx.fillStyle = cta.color;
  ctx.textAlign = cta.alignment;
  ctx.letterSpacing = `${cta.letterSpacing}px`;
  
  const x = cta.alignment === 'center' ? totalWidth / 2 : 
            cta.alignment === 'right' ? totalWidth - frame.padding : frame.padding;
  const y = cta.position === 'bottom' ? 
            frame.padding + qrSize + frame.padding / 2 + cta.fontSize :
            frame.padding / 2 + cta.fontSize;
  
  ctx.fillText(cta.text, x, y);
}
```

### Filename Convention

- Format: `qraft-{type}-{timestamp}.{ext}`
- Example: `qraft-url-20240115-143052.png`
- *Note:* Always sanitize any user-provided content if used in the filename.

## SVG Export

### Updated SVG Export Flow

1. User clicks 'Download SVG'
2. Get base QR as SVG string from `qr-code-styling`
3. If frame enabled:
   a. Create parent SVG with total dimensions
   b. Add frame rect/path elements
   c. Nest base QR SVG as `<g>` with transform offset
   d. Add `<text>` element for CTA if enabled
   e. Export parent SVG as blob
4. If no frame:
   a. Export base QR SVG blob directly
5. Trigger download

### SVG Frame Rendering

```typescript
function wrapSVGWithFrame(baseSVG: string, frame: QRFrame, qrSize: number): string {
  const ctaHeight = frame.ctaText ? frame.ctaText.fontSize + 16 : 0;
  const totalWidth = qrSize + frame.padding * 2;
  const totalHeight = qrSize + frame.padding * 2 + ctaHeight;
  
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${totalWidth}" height="${totalHeight}">
    <rect width="${totalWidth}" height="${totalHeight}" rx="${frame.borderRadius}" 
          fill="${frame.backgroundColor}" stroke="${frame.color}" stroke-width="${frame.borderWidth}"/>
    <g transform="translate(${frame.padding}, ${frame.padding})">
      ${baseSVG}
    </g>
    ${frame.ctaText ? `<text x="${totalWidth/2}" y="${totalHeight - 12}" 
      text-anchor="middle" font-family="${frame.ctaText.fontFamily}" 
      font-weight="${frame.ctaText.fontWeight}" font-size="${frame.ctaText.fontSize}" 
      fill="${frame.ctaText.color}" letter-spacing="${frame.ctaText.letterSpacing}">
      ${escapeXML(frame.ctaText.text)}
    </text>` : ''}
  </svg>`;
}
```

### SVG Security Note

- The generated SVG should **not** contain `<script>` tags.
- While the `qr-code-styling` library generates clean SVG by default, ensure that if any user-provided content somehow appears in SVG attributes, it is appropriately sanitized.

## Clipboard Copy

### Clipboard API

```typescript
async function copyQRToClipboard(blob: Blob): Promise<void> {
  try {
    await navigator.clipboard.write([
      new ClipboardItem({
        'image/png': blob,
      }),
    ]);
  } catch (err) {
    // Fallback or error handling
    console.error('Failed to copy to clipboard:', err);
    throw err;
  }
}
```

### Requirements

- The Clipboard API requires a secure context (HTTPS or `localhost`).
- Most browsers require a direct user gesture (like a click event) to write to the clipboard.
- Copy the **PNG format**, as it is the most universally pasteable image format across applications.
- **Success UI:** Show a success toast notifying "QR code copied to clipboard".
- **Error UI:** Show an error toast if the clipboard is not available or the operation fails ("Clipboard not available. Try downloading instead.").

### Browser Compatibility

| Browser | Clipboard Write Image | Notes |
|---|---|---|
| Chrome 76+ | ✓ | Full support |
| Firefox 87+ | ✓ | Full support |
| Safari 13.1+ | ✓ | Full support |
| Edge 79+ | ✓ | Full support |
| Mobile Chrome | ✓ | Requires secure context |
| Mobile Safari | ✓ | iOS 13.4+ |

### Fallback Strategy

If the Clipboard API is unavailable (e.g., non-secure context or incompatible browser):
1. Check for `navigator.clipboard` and `navigator.clipboard.write` existence on initialization.
2. If unavailable, show the 'Download' action as the primary action and hide the copy button.
3. Alternatively, disable the copy button and show a tooltip: "Copy requires HTTPS".
